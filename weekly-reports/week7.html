Week 7 Overview

Week 7 focused on transforming the ESP32 from a basic embedded controller into a connected IoT platform. The experiments progressively explored local web-based control, cloud messaging, voice-triggered actuation, Firebase-based monitoring, and autonomous sensor-driven automation.


Across the five experiments, the same core idea was extended through different trigger mechanisms:

Local browser command
Cloud message
Voice command
Cloud dashboard
Environmental sensing

The session helped connect embedded programming with networking, cloud services, web interfaces, physical actuation, and autonomous decision-making.

The Progression

The five experiments progressively changed the source of the decision — from a browser request, to a cloud message, to a voice command, to a cloud dashboard, and finally to the physical environment itself.
